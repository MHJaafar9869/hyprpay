Paymob's checkout flow is now composed as a Laravel pipeline of ordered steps.

### Changed
- `PaymobGateway::createCheckoutSession()` runs its authenticate → register-order → payment-key → build-session flow through an `Illuminate\Pipeline\Pipeline` of small pipe classes over a shared `PaymobCheckoutContext`, replacing the previous inline method. Behaviour and output are unchanged.

### Added
- Declared `illuminate/pipeline` as a direct dependency.
