CyberSource REST requests now send `Accept: application/hal+json` on every method, fixing a 404 on `/pts/v2/payments`.

### Fixed
- **CyberSource `/pts/v2/payments` 404 (Accept header)** — non-GET requests sent `Accept: application/json`, but CyberSource's edge returns `404 Resource not found` for `/pts/v2/payments` (and `/risk/v1/*`) with that type; only the Unified Checkout session endpoints tolerate it. A charge therefore failed with a 404 that masqueraded as an unprovisioned-merchant error, even though the capture-context call on the same credentials succeeded. `SignsCybersourceRequests` now sends `Accept: application/hal+json;charset=utf-8` on every request, which every endpoint accepts.
