Authorize.Net joins the SDK as the eighth gateway.

### Added
- **Authorize.Net gateway** — behind the same `PaymentGatewayInterface`: charge an Accept.js opaque-data token (immediate capture or authorize-only), capture a prior authorization, refund, void, look up a transaction, and verify the HMAC-SHA512 webhook signature. Resolve it with `GatewayName::AuthorizeNet`.
- `gateway:reconcile:authorize_net` reconciliation command and an `authorize_net` credentials block (API Login ID, Transaction Key, Signature Key) in the config.

### Documentation
- Authorize.Net added to the gateways guide (runnable sample + operation matrix), the interactive docs, and the landing page.
