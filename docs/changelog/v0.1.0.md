First public release of the self-contained, multi-gateway payment SDK for Laravel.

### Added
- Domain-driven core (ports &amp; adapters) with typed checkout-option DTOs, payment domain events and a listener, and per-operation logging via `LoggingGateway`.
- Gateway drivers: **Fawry**, **Paymob**, **PayLink** (including iframe checkout), **PayTabs**, **PayPal** (Orders v2 / Payments v2), and **CyberSource** (including Dynamic Currency Conversion).
- Pluggable HTTP client and credential-resolver ports.
- GitHub Pages documentation and landing site, GitHub Actions CI, and issue / pull-request templates.
