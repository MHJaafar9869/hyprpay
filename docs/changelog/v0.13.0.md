Expanded operation coverage for Airwallex, PayPal, and Mastercard MPGS — Dynamic Currency Conversion, digital-wallet charges, and transaction reconciliation — bringing the three drivers closer to the CyberSource Unified Checkout surface. All additions are backward compatible: new operations behind the existing `PaymentGatewayInterface`, no changes to existing behaviour.

### Added
- **MPGS Dynamic Currency Conversion** — a new `requestDccRate` operation posts a payment-options inquiry (`POST …/paymentOptionsInquiry`) with the order amount and the card BIN prefix, mapping MPGS's `currencyConversion` offer into a `DccQuote` so a charge can bill the cardholder in their own currency.
- **MPGS digital-wallet charges** — `chargeWallet` charges a merchant-decrypted Apple Pay / Google Pay token as a `PAY`/`AUTHORIZE`, flagging the wallet on `order.walletProvider` and sending the decrypted card plus online-payment cryptogram under `sourceOfFunds.provided.card.devicePayment`. Requires a `DecryptedWalletToken` — MPGS decrypts nothing itself.
- **MPGS transaction reconciliation** — `findSuccessfulTransactionByReference`, `listTransactions`, and `listTransactionsByReference` read an order's `transaction[]` history (RETRIEVE ORDER, `GET …/order/{id}`), mapping each authorization, capture, refund, and void to a snapshot newest-first; the order id is the merchant reference.
- **PayPal authorization reversal** — `reverseAuthorization` releases a held authorization by voiding it, since PayPal exposes no distinct reversal endpoint.
- **PayPal transaction reconciliation** — `searchTransaction`, `listTransactions`, `listTransactionsByReference`, and `findSuccessfulTransactionByReference` read PayPal's Transaction Search (Reporting v1) API. The query is a PayPal transaction id or a raw reporting query string; reference lookups pull a rolling window (31 days by default, overridable via the `reporting_window_days` credential extra) and match `invoice_id` client-side — PayPal reporting cannot filter by merchant reference and lags real time by a few hours, so a null result means "not found in the recent window", not "never happened".
- **Airwallex transaction reconciliation** — `findSuccessfulTransactionByReference`, `listTransactions`, and `listTransactionsByReference` list PaymentIntents by `merchant_order_id` (Airwallex's reconciliation key), returning the full history or the first authorized/captured intent.
