A dependency-compatibility patch.

### Changed
- Widen `firebase/php-jwt` to `^6.10 || ^7.0`. The SDK only uses APIs that are identical across php-jwt 6.x and 7.x, and the previous `^7.0`-only pin needlessly conflicted with consumers (such as `cybersource/rest-client-php`) that cap php-jwt below 7.

### Documentation
- Shorten the orchestrated-confirm navigation label in the interactive guide.
