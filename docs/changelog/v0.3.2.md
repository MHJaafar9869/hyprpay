Decision Manager device fingerprinting now flows through every CyberSource path.

### Added
- Carry `deviceInformation.fingerprintSessionId` on stored-credential (MIT/CIT) charges and on 3-D Secure payer-auth enrollment — it was previously sent only on the charge call.
- New REST `useRawFingerprintSessionId` flag across those flows.

### Changed
- Run Decision Manager in the orchestrated Unified Checkout flow via `completeMandate.decisionManager` (enabled by default).

### Documentation
- Document the browser profiling tag and CyberSource's standard device-fingerprint org ids in both guides.
