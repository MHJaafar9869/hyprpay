3-D Secure device data collection for CyberSource Unified Checkout, plus a log panel on the monitoring dashboard.

### Added
- **CyberSource 3-D Secure setup (device data collection)** — a new `setupPayerAuth` operation (`POST /risk/v1/authentication-setups`) that primes browser device data collection before enrollment, returning the device-data-collection URL, access token, and reference id to carry into `enrollPayerAuth`. Backed by `PayerAuthSetupRequest` / `PayerAuthSetupResult` and wired through the gateway interface, the abstract default (unsupported unless overridden), and the event-dispatching and logging decorators.
- **Browser device data on enroll** — `enrollPayerAuth` now accepts a `BrowserDeviceData` on `PayerAuthEnrollRequest.device`, mapped onto CyberSource's `deviceInformation` and merged with the existing fraud device fingerprint. When present, the enrollment's device channel is marked `Browser` so the issuer can risk-assess the browser and grant a frictionless (no-challenge) authentication more often.
- **Dashboard log panel** — the monitoring dashboard surfaces the SDK's `hyprpay`-channel log entries, newest first, each with an expandable context view that pretty-prints trailing JSON context and folds in stack-trace continuation lines. A top-bar auto-refresh toggle, disabled by default, polls the dashboard on an interval when enabled.
