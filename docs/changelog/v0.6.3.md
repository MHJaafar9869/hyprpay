The developer MCP server can now surface real-world integration gotchas per gateway.

### Added
- **Developer MCP `get_gateway_gotchas` tool** — a curated tool on the developer MCP server that returns the operational pitfalls reflection cannot show: header quirks (CyberSource's `application/hal+json` requirement), account entitlements (Airwallex Online-Payments activation, CyberSource Payments-API product, autoProcessing), required fields (Paymob's card iframe id, Airwallex's ≤32-char descriptor), idempotency rules (Airwallex's unique `request_id`), embedded-vs-redirect return shapes (`client_secret` vs `redirectUrl`), scoped-key headers (Airwallex `x-login-as`), and browser-SDK timing (Authorize.Net Accept.js loading `AcceptCore.js` asynchronously). Pass a gateway key for its notes, or omit for every gateway plus the general notes. The MCP is repo tooling and is not part of the Composer package.
