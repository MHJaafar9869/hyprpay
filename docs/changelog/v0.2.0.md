Adds a new gateway and PayLink stored credentials.

### Added
- **Mastercard Payment Gateway Services (MPGS)** gateway driver.
- PayLink card tokenization — store a card and revoke the token.
- PayLink `chargeStoredCredential` — charge a stored-credential token.

### Documentation
- Reworked the interactive guide: gateway selector moved to the left with the action list on the right, display font switched to Instrument Sans, hero banner and reading-progress bar removed, per-action intros now name only the selected gateway, and the CyberSource checkout client library, integrity fields, credential resolver and HTTP client ports are documented.
