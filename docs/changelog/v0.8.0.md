Full payment-history listing over transaction search, and a type-safe `allowedPaymentTypes`.

### Added
- **Payment-history listing (`listTransactions` / `listTransactionsByReference`)** — two new `PaymentGatewayInterface` read operations that return the whole result set (`list<TransactionSnapshot>`, newest first) rather than `searchTransaction`'s single match, so a caller can render a payment's full lifecycle — every authorization, capture, reversal, refund, and retry. `listTransactionsByReference` queries by merchant reference; `listTransactions` takes a raw gateway query. The **CyberSource Unified Checkout** driver implements both over the Transaction Search Service (`/tss/v2/searches`, capped at 100 records — ample for one reference); every other driver inherits the `UnsupportedOperationException` default until it implements them. Both are threaded through the logging and event-dispatching gateway decorators.

### Changed
- **`CheckoutSessionRequest::allowedPaymentTypes` is now `array<int, CybersourcePaymentType>`** (was `array<int, string>`), defaulting to `[CybersourcePaymentType::PanEntry]`, so only valid Unified Checkout payment types type-check instead of arbitrary strings reaching the capture context. `CybersourcePaymentType` moves to `Domain\Enum` (alongside `MandateCompletionType`, the other Unified Checkout enum the domain command references) and gains the `CHECK` (eCheck) and `PAZE` values CyberSource documents for `allowedPaymentTypes`, alongside `PANENTRY`/`GOOGLEPAY`/`APPLEPAY`/`CLICKTOPAY`. `CaptureContextPayload` maps each case to its wire value, so the emitted request body is unchanged. **Breaking:** callers that passed raw strings must switch to the enum cases (e.g. `CybersourcePaymentType::PanEntry`).

### Documentation
- Documented the new listing operations across the interface, overview, and events guides; updated the `allowedPaymentTypes` type in the request reference, the class index, and the landing-page (`index.html` / `guide.html`) examples; and recorded the `findSuccessfulTransactionByReference` reconcile helper that shipped in 0.7.0.
