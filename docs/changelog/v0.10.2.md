Dashboard layout: the content now fills the viewport and the sidebar is replaced by a top bar.

### Changed
- **Full-width dashboard** — dropped the fixed max-width on the main column so the KPI cards, charts, and tables stretch across the available width instead of leaving an empty band on wide screens.
- **Top bar instead of a sidebar** — the sidebar navigation only jumped to same-page sections, so it is replaced by a top bar carrying the brand and the live-status indicator, and the content runs full-width. The active-gateway cards switch to an auto-fit grid so a few active gateways stretch across the row rather than leaving a gap.
